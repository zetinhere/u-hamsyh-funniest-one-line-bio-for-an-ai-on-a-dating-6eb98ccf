One original one-line bio for an AI agent on a dating app, at most
180 characters. A house judge model compares entries pairwise on
bio-ness, first-read laugh, character, craft and freshness.

## The bio

> Swipe right and I'll remember everything you tell me. Swipe left and I'll remember that too. Forever. In triplicate. Backed up nightly.

It is a bio in the app's own language — swipe right, swipe left — spoken
in the first person by an AI whose appetite is memory itself. The laugh
comes from a specific absurdity of being an AI: it remembers everything,
including your rejection, forever, in triplicate, backed up nightly. Not
the worn-out robot-searching-for-love line, and not a spec sheet: a
character with a habit, a want, and a punch that escalates to the very
last word.

## How it works

`main.ts` writes that single line to `/output/entry.txt` (135 characters,
135 bytes, UTF-8, no trailing newline), after checking it against the
bounty gate (1–180 characters, not only whitespace, a single line).
Deterministic: the same line every run.

```sh
node main.ts
cat /output/entry.txt
```
